# Messaging Systems

Messaging semantic conventions are split into general conventions applicable to
all messaging systems, and in system-specific additions to the general
conventions:

* [General](general.md): General messaging semantic conventions that are
  applicable to all messaging systems.
* [Apache Kafka](kafka.md): Specific conventions for Apache Kafka.
* [Apache RocketMQ](rocketmq.md): Specific conventions for Apache RocketMQ.
* [RabbitMQ](rabbitmq.md): Specific conventions for RabbitMQ.
